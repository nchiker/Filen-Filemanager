Filen Files 0.4.6

- New: **Public links** - make a link to a file or folder with an expiry (default 1 week), an optional password and a download switch; copy, change or remove it, and see all your links under Home > Tools > Links. Needs a Filen plan that includes public links.
- New: **Updates inside the app** - the "Version X is available" banner now has an Update button: it downloads the new APK, checks it (checksum, same app, newer version, same signing key) and hands it to Android's installer, which asks you to confirm. No browser trip. The first time, Android asks you to allow Filen Files to install apps.
- New: sort menu has explicit **Ascending / Descending** options.
- Fix: the link dialog no longer stays disabled while its confirmation message shows.

Install: download the APK on an arm64 Android 8.0+ phone and open it. Updates install over the previous release.
