Filen Files 0.4.5

- New: **Available offline** - pin files or folders of your Filen drive; they stay on the phone, follow changes made on the web, and open with no connection (Home > Tools > Offline). Pinned copies are stored unencrypted in the app's private storage and wiped when you sign out.
- New: **Search filters** - Type, Date and Size chips next to the existing scope chips.
- New: **Storage quota** bar on Home and in Settings.
- Updated the Filen SDK to 0.5.33 (ICO and animated PNG thumbnails, updated TLS roots).
- Fixes: two compiler warnings, search results beyond the first 100 names when a filter is on.

Install: download the APK on an arm64 Android 8.0+ phone and open it. Updates install over the previous release.
