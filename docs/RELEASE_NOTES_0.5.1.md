Filen Files 0.5.1

**Please update. In 0.5.0, saving over a file you had shared on its own ended the share: your partner lost the file.** After updating, check files you shared that way and saved since, and share them again if needed.
- Fixed: a file shared on its own stays shared when you save over it. Only people who already had it get the new version. If that can't be done, the upload says so.
- Fixed: files opened under "Shared by me" are recognised as yours. Ami Pro 0.7.1 no longer asks you to save them into Filen before sharing.
- New: an app you give one file under "Shared by me" can save over it (file versioning must be on), and it still opens after you stop sharing. Access to a whole folder there stays read-only.
- Safety: an app with access to a folder can no longer use Android to turn it into separate access to a single file.
- Better: "Stop sharing" also covers a version saved while you were stopping.
- Not covered yet: restoring an old version may end a file's own share. If you stop sharing on another device while this one is still uploading a save, check that it stayed stopped.

Install: download Filen-Files.apk on an arm64 Android 8.0+ phone and open it. Updates install over the previous release.
