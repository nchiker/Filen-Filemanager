Filen Files 0.4.7

Works with the Stack app (Stack link). Nothing to set up on your side.

- New: **Stack can find and follow your Filen files.** A document that lives in Filen keeps its link when you rename, move, trash or delete it, or remove its public link or share: Filen tells Stack, and Stack updates its record. If Stack is not installed or is locked, nothing changes for you.
- New: Stack and Ami Pro can ask Filen which Filen file a document is (and whether it still exists, is in the trash or is shared). Only those two apps, checked by their signature, may ask.
- New: **Open a shared document from Stack** straight in Filen.
- New: **Change notice for shared folders**: when a folder shared with you changes, apps you gave access to (Stack) are told, while Filen Files is running and about every 6 hours otherwise.
- New (not yet tested with two accounts): **pairing with a partner for Stack.** Stack can ask Filen to connect two Filen accounts as contacts and share one folder ("Stack shared"). Each phone shows one Allow dialog with the other person's email; nothing is shared before you tap Allow. Only Stack can start it.
- Fix: a file another app saved into Filen (for example Ami Pro) can be opened again right after saving, also before its upload has finished.

Install: download the APK on an arm64 Android 8.0+ phone and open it. Updates install over the previous release.
